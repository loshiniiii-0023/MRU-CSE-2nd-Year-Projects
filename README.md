# FloodWatch – Flood Alert & Resource Coordination System

**Project Type:** Web Development

**Description:** FloodWatch is a web-based flood alert and resource coordination system designed to help people access flood alerts, report flooded areas, locate nearby shelters and coordinate emergency resources.

**Technologies Used:**
- Next.js
- React
- TypeScript
- Tailwind CSS
- Firebase Authentication
- Firebase Firestore
- Firebase Storage
- Leaflet and OpenStreetMap

**Live Website:** https://flood-opal.vercel.app/
