# 🌊 FloodWatch – Flood Alert & Resource Coordination System

## 📌 About the Project

FloodWatch is a web-based Flood Alert and Resource Coordination System developed as a college mini project. It aims to help people access flood-related information, report flooded areas, locate nearby shelters and coordinate emergency resources through a single platform.

The system provides a simple interface where users can view flood alerts, explore affected locations on a map and find essential emergency resources.

## 🎯 Objectives

- To provide information about flood alerts and affected areas.
- To help users report flooding incidents.
- To help people locate nearby shelters.
- To display flood-related locations on an interactive map.
- To support coordination of emergency resources.

## ✨ Key Features

1. **Dashboard** – Displays flood information, alerts and important statistics.
2. **Flood Alerts** – Shows flood warnings, affected areas and safety instructions.
3. **Live Flood Map** – Displays flood-related locations using an interactive map.
4. **Shelter Finder** – Helps users find nearby shelters and view their availability.
5. **Report Flooding** – Allows users to submit reports about flooded areas.
6. **Admin Dashboard** – Provides a coordination interface for monitoring reports, alerts, shelters and resources.

## ⚙️ Installation and Setup

To run the project locally:

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd FloodWatch
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure Firebase**

Add the required Firebase configuration through environment variables in a local `.env.local` file. Do not upload private credentials to GitHub.

**5. Start the development server**

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
